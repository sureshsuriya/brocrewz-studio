## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS (Glassmorphism theme), Framer Motion
- **Backend:** Java 21, Spring Boot 3, Spring Security, JWT, MySQL
- **DevOps:** Docker, Docker Compose, GitHub Actions

## Project Structure
- `/frontend` - React application
- `/backend` - Spring Boot application
- `docker-compose.yml` - Root orchestration file

## Getting Started

1. Clone the repository.
2. Ensure you have Docker installed.
3. Run the following command at the root:
   ```bash
   docker-compose up --build
   ```
4. Access the frontend at `http://localhost:80` (or `http://localhost:5173` if running `npm run dev`).
5. Backend APIs run on `http://localhost:8080`.
