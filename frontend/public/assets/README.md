# Asset Placements

This directory is the root for all static media assets (images, videos, graphics). Since they are inside the `public` folder, they will be served directly at the root path of the deployed website. 

For example, an image at `public/assets/logo/brocrewz-logo.png` can be accessed in the React code via `<img src="/assets/logo/brocrewz-logo.png" />`.

Please place your image files in the corresponding folders as described below. Make sure the file names match exactly what is listed here so the code does not break!

## 1. Logo
Location: `/public/assets/logo/`
- `brocrewz-logo.png` (Main Logo - transparent background recommended)
- `brocrewz-logo-dark.png` (Optional, if you have a dark mode variant)
